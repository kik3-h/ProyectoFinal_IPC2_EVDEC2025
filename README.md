# ProyectoFinal_IPC2_EVDEC2025

Proyecto final IPC2 - Escuela de Vacaciones Diciembre 2025. Un proyecto integral dividido en 3 fases: documentación, entregables y complementación.

## 📋 Descripción

Este proyecto es el trabajo final del curso IPC2 desarrollado durante la escuela de vacaciones de diciembre 2025. Está estructurado como una aplicación full-stack con componentes de frontend y backend separados.

## 📁 Estructura del Proyecto

```
ProyectoFinal_IPC2_EVDEC2025/
├── Backend/          # API y lógica del servidor
├── Frontend/         # Interfaz de usuario
└── README.md         # Este archivo
```

## 🚀 Instalación

### Requisitos Previos
- Node.js (v14 o superior)
- npm o yarn

### Backend
```bash
cd Backend
npm install
```

### Frontend
```bash
cd Frontend
npm install
```

## 🔧 Uso

### Ejecutar el Backend
```bash
cd Backend
npm start
```

### Ejecutar el Frontend
```bash
cd Frontend
npm start
```

## 📅 Fases del Proyecto

1. **Fase 1: Documentación** - Especificación y diseño del proyecto
2. **Fase 2: Entregables** - Implementación de funcionalidades principales
3. **Fase 3: Complementación** - Mejoras, optimizaciones y detalles finales
